# newsroom

A small Hacker News reader. The browser app lists top stories and asks for an extractive
"summary" of a story's discussion; the summary is produced asynchronously by a Rust worker.

## Services

| service | folder | stack | port |
|---|---|---|---|
| `web` | `web/` | TypeScript, client generated by `@hey-api/openapi-ts` into `src/generated/`, esbuild bundle, tiny Node static server (`server.ts`) | 41020 |
| `api` | `api/` | Python 3.13, FastAPI (`/api/v1` app prefix + `APIRouter` prefixes), httpx, redis-py asyncio | 41010 |
| `summarizer` | `summarizer/` | Rust, tokio + redis crate + reqwest | - |
| redis | docker `tiny2-newsroom-redis` | `redis:7-alpine` | 41079 |

Flow: web -> api `GET /api/v1/stories/top` (api -> HN API) -> web `POST /api/v1/summaries` -> api `LPUSH newsroom:summaries:jobs`
-> summarizer `BRPOP`, fetches top comments from the HN API, `POST /api/v1/internal/summaries/{job_id}/result` back to api,
then `PUBLISH newsroom:summaries:done` -> api subscriber marks the summary ready -> web polls `GET /api/v1/summaries/{story_id}`.

`./run.sh` installs deps, starts everything, drives the web client from Node (`web/scripts/drive.ts` imports the same
`src/newsroom.ts` / generated SDK the browser bundle uses), and writes `observed.log`. `TRUTH.json` is the answer key.
To regenerate the client: export `app.openapi()` to `web/openapi.json`, then `cd web && npx openapi-ts`.

## Idioms tested

- OpenAPI-generated TypeScript SDK (`@hey-api/openapi-ts`): paths live only in generated `sdk.gen.ts`, the request is sent
  by a generic `fetch` in the generated client, `baseUrl` is set once with `client.setConfig`; app code calls `listTopStories(...)` etc.
- FastAPI app-level prefix (`include_router(api_router, prefix=API_PREFIX)`) over a nested router that includes per-area
  `APIRouter(prefix=...)` routers; an empty-string route path; a router hidden from the schema (`include_in_schema=False`).
- httpx `AsyncClient(base_url=...)` with a base that itself has a path (`/v0`), relative literal and f-string paths, calls fanned out with `asyncio.gather`.
- Redis list as a job queue across languages (redis-py `lpush` -> redis crate `brpop`), queue name from env-backed settings on both sides.
- Redis pub/sub back the other way (redis crate `publish` -> redis-py `pubsub.subscribe` in a lifespan background task).
- reqwest URLs built with `format!` through a small `endpoint()` helper, base from an env var with a default.
- Outside links declared in HTML (`<link rel="stylesheet">`, `<a href>`), plus a `<link rel="preconnect">` that is not a request.

## Not observable / caveats

All 12 links show up in `observed.log`. H01/H02 are HTML references; `scripts/drive.ts` fetches the URLs it parses out of
`index.html` and logs them as the caller (no headless browser is used).
